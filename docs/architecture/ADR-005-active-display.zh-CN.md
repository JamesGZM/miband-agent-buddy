# ADR-005：活动任务期间保持亮屏

[English](ADR-005-active-display.md) · **简体中文** · [繁體中文](ADR-005-active-display.zh-TW.md)

## 问题

一次性租约可能在 AI 思考、调用工具或等待权限时到期。每份指标都延长普通租约会阻止空闲息屏，主机异常后也可能持续耗电。一个任务结束不能遮蔽并发任务。

## 决策

`activityKeepAwake` 持久化且默认 false，旧配置升级也一样。类型化 `activity_keep_awake` 保存并立即更新运行时，无需重连。关闭时，事件与手动唤醒仍使用有界单次租约。

每次明确设置操作在链路可用时唤醒一次，无论重复值或开关方向；显示唤醒／应用／结果，并等待匹配回执。普通配置不发起额外启动。断线或安装中只保存意图。同步暂停仍允许手动有界交易，但不续期任务或恢复背景同步；恢复同步且任务仍活动时唤醒一次。

`syncEnabled` 默认 true，窗口和托盘持久化同一状态，启动先恢复暂停再自动连接，避免关闭同步后重启短暂发送。

传输重连认证后，只有同步开启、任务亮屏开启且任务仍活动时，请求一次 `activity_reconnect` 唤醒，不需要新的 Hook。认证及实际发送前均检查最新任务与设置，排队期间取消会丢弃恢复请求；重复认证被忽略。空闲、已结束、暂停或关闭时不启动。它替代了无条件安静重连，修复活动任务断链后一直黑屏；不是周期重开，仍受冷却与唤醒／ACK 期限限制。

Buddy 0.5.4 声明 `capabilities.activityHold=true`，运行时在匹配 ACK 观察到能力后才发送成对 v1 字段 `activityHoldMs` 与 `idleHoldMs`。启用且 activeSessions 非零时前者为 15,000 ms，否则为零；后者为保存的 5–1800 秒待机宽限。关闭亮屏只启动一次宽限，不清除任务。聚合活动优先于单个会话的完成动画。

手环每份有效活动快照续期 15 秒本地看门狗。成功亮度请求每 30 秒刷新，失败或回调超时后两秒重试，success 中负的 native value 也算失败。两秒普通快照只移动期限。首次活动转空闲时启动一次待机宽限，后续空闲快照不延期；活动中的手动唤醒保留看门狗，不替换为长待机租约。

资源采样不控制任务传输，最多一个采样工作。数据最多沿用两个采样间隔，之后显示未知，采样异常或文件系统卡住仍发送活动与终止快照；停止后迟到结果不能恢复运行。它替代每次发送前等待完整采样；不使用重叠重试，以免文件系统卡住时堆积工作。

断线、暂停、安装或关闭导致快照停止时，本地看门狗到期释放。hide／exit／destroy 取消定时器并使旧回调失效，重复快照不能续期。重新显示需新快照，缓存活动不会自行恢复。`wakeDisplay.active` 表示活动租约，`remainingMs` 是看门狗而非用户待机时长。

15 分钟无事件后标记 stale，并暴露 freshActiveSessions／staleSessions；这只是警告，长工具或思考可数小时无事件，终止事件或明确重置前仍保持活动与续期。部分客户端取消时不发终止事件，例如某些 Claude Code Escape；不能用时间猜测真实任务已结束。

`reset_activity` 清除会话及排队／进行中的 Hook 唤醒，保留历史计数。桌面带 request ID 的重置即使暂停也唤醒一次、等待显示回执；旧的不带 ID 命令仍只清本地。不取消或授权 AI 工作。

## 替代方案

- 永久亮屏无法在主机失效后本地恢复。
- 每份指标延长长租约会妨碍息屏并放大断线耗电。
- 定时重新启动会干扰用户导航，正常会话不使用该策略。

## 兼容

v1、`keepScreen=false`、唯一 wake ID、数据路径和事件策略不变；旧版保留单次租约，每次连接重新协商能力。Rust 保留可加字段，桌面与手环版本独立。

支持能力的快照还可带 `sessionCounts`，思考／执行／等待均为非负整数，总计最多 128，与亮屏开关独立。纯共享显示函数把并发数映射到原有圆环内最多六色，不增加文字。颜色不代表 provider，也不包含任务名、会话 ID 或内容；过期或空闲恢复原环。

## 证据

界面参考 [Code Light AI](https://github.com/cuihp/code-light-ai) 的聚合优先级与并发显示，以及 [AgentHUD](https://github.com/garunnir/AgentHUD) 的紧凑状态。Buddy 只用手选角色与原圆环颜色适配小屏，不复制源码、图像或读取对话的实现。

假时钟覆盖默认关闭、手动双向操作、暂停与启动、八小时无新 Hook、聚合、单次宽限、过期警告、重置回执、断线／暂停过期、重复包、旧回调、隐藏页及旧版能力；新增采样异常／卡住、负值 success、快速重试与活动重连恢复。Rust 验证旧配置、持久化和 UI 投影，共享 fixture 验证边界。物理亮屏仍需设备观察，ACK 不构成证明。
