# ADR-015：合併事件喚起

[English](../../en/architecture/ADR-015-coalesced-event-wake.md) · [简体中文](../../zh-CN/architecture/ADR-015-coalesced-event-wake.md) · **繁體中文**

## 問題

重複的任務開始 Hook 會在 Buddy 已顯示且保持亮屏時再次請求原生啟動。冷卻時間只是延後重複打開，沒有消除副作用。

## 決策

Mac 繼續計算聚合狀態、優先級與任務顏色。目前連線的新鮮 ACK 確認頁面可見、亮屏已接受且租約未過期時，事件優先發送快照。並行 Hook 合入已有的有界顯示交易，快照攜帶最新聚合結果。每任務完成記錄獨立於顯示合併。若下一個回執明確報告隱藏或關閉亮屏，同一交易可在原截止時間內啟動一次。使用者手動操作保留現有原生喚起行為。

## 替代方案

永久按會話與事件去重會吞掉同一對話的合法後續輪次；延長冷卻只會推遲重複打開。手環推斷任務會違反職責並增加設備負擔。

## 相容與證據

不改變設備協議或渲染器。舊版 Buddy 缺少前台證據時保留原生喚起。暫停、斷開、安裝、恢復及定時器邊界保持。假時鐘測試涵蓋雙會話、突發事件、合法後續輪次、注意與完成、延遲啟動、隱藏競爭和缺失 ACK。本機健康計數區分原生啟動和快照喚起。這些證據證明消除了重複打開，不能證明物理設備重啟的原因或已解決。
