# ADR-016：內建通用 AI 接入

[English](../../en/architecture/ADR-016-bundled-integration.md) · [简体中文](../../zh-CN/architecture/ADR-016-bundled-integration.md) · **繁體中文**

## 問題

平台卡片和依賴 checkout 的安裝要求使用者理解宿主內部實作，未知工具無法直接使用安裝器。接入需要隨 App 提供、不干預原任務，並正確處理並行對話。

## 決策

預設請求是跨本機專案和新主對話的使用者全域自動回報，採用宿主實際支援的機制，不強制 Hooks。本輪完成可做的持久設定，不得擅自降級為專案範圍或僅測通 CLI。最小適配器按需使用，不擴展成安裝框架，生命週期獨立於專案和其他 App 的私有環境。優先背景觀察，在宿主有序邊界保留事件順序；僅有鎖和 runtime 水位無法恢復背景到達順序。必須同步的處理器只做最小有界本機接收或交接；300ms 入口時限不等於總回呼時延。宿主啟用、真實後續輪次和不同專案自動回報分開驗證；原生信任或重載未完成時保持待驗證。

對話自動回報分為兩個獨立選擇：已驗證的宿主生命週期觸發器，以及 內建 CLI 投遞。連通或合成回執僅證明通道可用。接入必須建立已載入的主對話回調，並用後續一般使用者輪次驗證，無需模型臨時補發通知。缺少可靠觸發或宿主尚未載入時，自動接入仍未完成；模型自行呼叫與手動回報必須分開標識。不得將名稱相似的 CLI/SDK 能力直接套到桌面對話。

桌面程式在 Tauri 啟動前處理 `--buddy-cli`，使用內建 Node。宿主 Hooks 或已驗證的生命週期回調呼叫 CLI，經私有 loopback 提交至唯一 runtime，不新增對外 API 或藍牙擁有者。接入頁複製完整接入說明與應用身分，不提供文件連結或安裝目錄；AI 透過應用登錄解析入口，選擇宿主可靠回調、保留設定並報告缺口。

嚴格合約只包含匿名 source/session、遞增 run/seq 和列舉狀態，入口雜湊身分，不保留內容。同一對話只有一個主要回報器，回調在後續輪次共用身分。Runtime 負責去重、排序和聚合，已結束輪次不可重開。最多保留 128 個通用對話水位至重設或重新啟動；滿額拒絕新身分而不擠掉活動。每對話限流另預留一次結束事件。連線不是對話。

CLI 本機接收時限 300ms，不等待裝置。宿主限制程序啟動時間，依對話序列化回調，避免無界程序堆積；獨立對話可並行呼叫 CLI。排程和程序啟動另有延遲。失敗回傳明確結果但繼續原任務，不輪詢或反覆重試。裝置交付沿用串行傳輸與快照合併。等待提醒必須有可靠解除；靜默或斷線不代表完成。

## 替代方案

額外對外 API 重複入口；MCP 增加設定與工具探索，卻不提供命令型 Hooks 的生命週期觸發，因此移除服務、入口與專用 schema／測試。下載原始碼或要求系統環境不符合自包含安裝。等待手環會阻塞任務，盲目背景提交無法證明接收。宿主設定仍有差異，但無需平台選擇頁。

## 退役原始碼安裝器

從 scripts 目錄移除 `install_agent_hooks.mjs`、`install_codex_hooks.mjs` 及安裝器專屬測試。繼續保留舊平台自動寫入器會與宿主自選的通用接入衝突。公開命令 `npm run hooks:install` 保留為唯讀 `buddy-cli.mjs guide` 別名，不再寫入設定，也不支援舊安裝參數。測試驗證此入口輸出完整指南且不修改宿主設定，並保留兩個 Mac 相容入口。既有事件發送器、接收合約與使用者本機備份不變。ADR-004/013 的安裝器歷史記錄不代表目前操作方式。

## 相容性

桌面包改用共用的明確資源邊界，不再複製整份開發目錄和清單。保留正式 JavaScript 模組、最小模組類型／版本／授權資訊，以及 CLI guide/help 使用的唯一目前接入指南；不帶入 fixtures、測試、額外筆記或開發命令。完整授權／來源資料在獨立區域保留。整份清單會帶入已退役安裝命令，刪除目前指南則會破壞離線 CLI。以封裝測試與搬移包執行驗證邊界，不改變執行時行為。

聚合狀態以 `source: "buddy-activity"` 標識子系統，新增 `scope: "aggregate"`。原先寫死的 `codex-hooks` 並非實際來源歸因。計數與時間戳涵蓋所有對話，不能據此判斷某個輪次狀態或 Hooks 設定，應驗證該輪次的回報回執。匿名輸入 source 身分不變，也不在狀態中暴露。

保留舊 Hook 連接埠、相容入口、v1 合約、私密路徑與 npm 命令。CLI 旗標及匿名欄位不變。明確退役 MCP 入口，接入 AI 應預覽後僅移除宿主的 Buddy MCP 登錄項；不自動遷移舊 Hooks 或重複回報。不改手環、不新增雲端或遙測、不發佈或安裝全域設定。

## 入口檔案身分

內建 CLI 和 runtime 比較正規化後的真實檔案身分，不再直接比較模組 URL 與 argv 路徑。Node 可能解析符號連結入口，同時在 argv 中保留別名，字串比較會靜默跳過啟動。檔案系統查詢由一個 runtime adapter 負責，不進入 core；缺失或非檔案參數按匯入處理。僅比較檔名可能誤啟動被匯入的服務，要求所有呼叫方自行正規化路徑也不可靠。預設解析和 preserve-symlinks-main 都保持直接入口行為，不改變協定或設定。真實子程序的連結目錄回歸測試先重現空說明輸出，身分判斷和正式資源匯入測試保留匯入無副作用；發布歸檔測試另在連結的 macOS 暫存目錄驗證。

## 證據

測試涵蓋內容拒絕、身分隔離、同毫秒與舊輪次排序、去重、結束、容量／限流、隔離接收器、逾時與真實 CLI 並行程序。新輪次首個 working 事件要求有界開始喚醒；同輪次 thinking 視為恢復，工具流量不反覆開啟手環。回歸測試涵蓋首次 working、同輪切換與下一輪；既有冷卻與連線恢復保留。簽名包、搬移與已安裝 App 分別驗證。宿主回調與實體亮屏仍需觀察。
