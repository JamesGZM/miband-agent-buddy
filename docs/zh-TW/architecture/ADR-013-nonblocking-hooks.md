# ADR-013: 非阻塞觀察 Hooks

[English](../../en/architecture/ADR-013-nonblocking-hooks.md) · [简体中文](../../zh-CN/architecture/ADR-013-nonblocking-hooks.md) · **繁體中文**

歷史決策：原始碼安裝與 skill 分發已由 [ADR-016](ADR-016-bundled-integration.md) 取代。舊安裝腳本已移除，原 npm 命令改為輸出離線指南。下述事件合約與隱私決策仍適用。

## 問題

同步命令會等待本機 HTTP，接收端無回應時約 600ms；錯誤放行不代表不等待。舊安裝器也不會升級已匹配命令的同步欄位。

## 決定

支援時使用原生 async。CLI 先去除私密內容，再啟動忽略標準管道的獨立發送程序；不等待 HTTP。輸入上限 150ms，HTTP 600ms，發送程序 1.2 秒。Codex SessionEnd 只執行短入口。不重試、不儲存原始輸入。時間戳在讀取輸入與派發前產生；忽略較早事件，同毫秒終止狀態優先。重裝僅升級自有 async/timeout，保留備份、原子寫入及其他設定。

## 替代方案

僅縮短逾時仍會阻塞；無限背景程序會洩漏資源，繼承管道會延長宿主等待。持久佇列需要新增儲存與生命週期契約。僅原生 async 無法涵蓋 SessionEnd 與自訂 harness。

## 相容性

保留相容入口、函式庫發送 API、會話雜湊及三欄位協定。盡力送達，宿主背景入口可能亂序或在退出時取消；發送時間不是宿主序號。較晚毫秒的新提示可重啟會話。

## 證據

測試涵蓋獨立程序、關閉管道、非法與未結束輸入、隱私、設定升級、無副作用匯入及亂序事件。程序啟動仍有少量開銷；宿主載入、信任和手環實物回應需單獨觀察。

## Cursor 本機相容

本機 Cursor 入口透過可測試的轉接程式使用相同的限時背景發送，保留 custom 命名空間、會話身分和既有命令路徑。preToolUse 需要有效權限回應，空物件可能被當成格式錯誤；輸入或啟動失敗時仍回傳不攔截回應，不修改其他 Hooks 的決策。測試涵蓋生命週期與隱私映射、派發失敗、未結束輸入和回應格式。
