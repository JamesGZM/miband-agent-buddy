# 更新記錄

[English](../../CHANGELOG.md) · [简体中文](../zh-CN/CHANGELOG.md) · **繁體中文**

這裡記錄主要變化。桌面 App 與 Buddy 分別維護版本。

## [0.7.10] - 2026-11-13

### 改善

- Buddy **0.5.21 / code 44** 監聽 interconnect 通道開啟、關閉及錯誤，限制可選就緒查詢的等待時間，通道恢復後最多補送一次最新 ACK。沒有就緒查詢 API 的舊韌體仍可使用。
- Buddy ACK 缺失後立即探測裝置，允許一次快速新快照重試；首次探測失敗後先給快照回覆機會，第二次探測失敗才允許重建傳輸。明確使用者操作優先於背景探測，獨立探測 ID 拒絕遲到結果。
- 自動重連後保留首個觀測異常的時間、層級與原子程序退出資訊。本地健康記錄只輸出白名單通道計數及安全錯誤碼。
- 內建 AI 接入說明補充穩定對話身分、重複回報處理及可恢復的結束投遞要求；完成和取消不能只依賴宿主可能取消的背景回呼。

### 驗證界線

- 本地通過 427 項 Node 測試、架構檢查、46 項桌面 Rust 及 18 項傳輸 Rust 測試。通道手測版已安裝並收到開啟事件及應用 ACK；長期穩定性及此前返回首頁的原因仍未驗證。
- Mac 套件維持 ad-hoc 簽章，未經 Apple 公證。Windows 安裝套件未簽章且仍屬實驗版本；Windows 藍牙/SPP 尚未實機驗證。

## [0.7.9] - 2026-11-13

### 改善

- 接入預設要求宿主支援的使用者全域自動機制，驗證跨專案及後續輪次。保持最小觀察型接入，不預設另造安裝框架、不綁定專案執行依賴，也不為排序而同步阻塞主流程；區分 CLI 接收時限與完整回呼時延。
- 桌面 App 內建完整 CLI 接入說明與報告入口，AI 接入頁面支援查看和複製宿主生命週期回呼的設定說明，無需原始碼目錄或外部 Node 安裝。
- 透過執行中的 runtime 接收有界、無內容的活動報告。匿名對話標識、執行／序號水位、終態保護和速率限制保持並行任務獨立，並拒絕過期投遞。
- 退役儲存庫 Hook 安裝腳本和內建安裝技能，保留既有 runtime Hook 相容性。`npm run hooks:install` 改為只列印接入說明，不修改宿主設定；既有回呼繼續保留，設定變更交由宿主自身流程完成。
- Mac 與 Windows 共用明確的正式資源打包規則，排除開發腳本和測試資料，保留目前接入說明及第三方授權聲明。

### 修復

- 透過真實檔案身分識別 CLI 與 runtime 入口，修復 App 搬移到符號連結暫存目錄後成功退出卻無 CLI 輸出的問題；模組匯入仍不會啟動服務。
- 新通用任務首次報告 `working` 時，按使用者啟用的設定喚醒休眠中的 Buddy；同一輪思考／工具更新不再被當成新任務開始。
- 彙總活動不再被錯誤歸因於某個 AI 提供者。

### 驗證限制

- 取代未發布的 v0.7.8 失敗嘗試，保留原標籤；搬移套件檢查已在發布前攔截入口問題。
- Buddy 維持 **0.5.20 / code 42**，本版無需更新手環套件。使用者已確認 CLI 首次 working 修復後的短時實機喚醒，以及新版 App 接入說明的手動複測。各宿主自動回呼及長期裝置穩定性仍未驗證。
- Mac 安裝包繼續使用 ad-hoc 簽名，未經 Apple 公證。Windows 安裝包仍無簽名且為實驗性版本；Windows 藍牙／SPP 尚未在真機實測。

## [0.7.7] - 2026-11-12

### 修復

- 需要用戶時外圈整圈變黃，恢復後還原任務配色。由安裝 Agent 按已驗證的宿主生命週期選擇可選提問接入，不把非同步工具返回誤判為用戶回答。
- 將並行 AI Hook 合入同一有界顯示交易。新鮮的前台亮屏回執允許只發送快照，避免重複原生啟動；頁面隱藏競爭保留一次有界兜底。
- Buddy **0.5.20 / code 42** 在突發快照時，僅在下一個動畫 tick 繪製最新主機計畫。ACK、亮屏租約、完成通知和切頁仍立即處理。
- 安裝助手成功啟動前保留驗證包；失敗清理半成品旁置目錄，支援重新校驗後重試，無需再次下載。
- Codex／Claude 觀察型 Hook 透過有界背景程序投遞，升級自有非同步設定並保留事件順序防護；新增非阻塞 Cursor 適配器。只能同步的生命週期 Hook 仍限制入口等待時間。

### 改善

- 透過 `buddy-updates.ailaogong.men` 檢查版本並串流下載 Mac 安裝包；服務、傳輸、大小或校驗失敗時直連 GitHub 官方來源。保留歸檔、架構、包標識與簽名驗證。
- 文件按語言歸組，根目錄僅保留一個 README，多語言主頁移到 `docs/readme`，改善不透明背景預覽圖與導覽。

### 驗證限制

- 回歸測試、本機簽名建置、Buddy 安裝、線上 Worker 安裝包驗證和 CI 已通過。雙 Agent 長時間實機穩定性、韌體記憶體及面板幀率仍未驗證；本版不宣稱已證實裝置重啟原因。
- Mac arm64／x64 DMG 與 ZIP 使用 ad-hoc 簽名，未經 Apple 公證。Windows x64／ARM64 安裝包仍無簽名且為實驗性版本，藍牙／SPP 尚未在 Windows 真機實測。
- 更新元資料可能快取十分鐘。GitHub 仍為發佈來源，專案 Worker 是新增的可信元資料中間層。見[更新交付](development/updates.md)。

## [0.7.6] - 2026-11-12

### 改善

- Buddy 0.5.18 角色頁改用完整原生邊框、快取任務色裁剪視窗、單層呼吸覆蓋與固定 Loading 槽位。縮小字形邊界並原位提交樣式，限制模型寫入，動畫更新工作不隨任務數增加。
- 活動租約協商上限為 120 秒，保留舊版 15 秒回退。先前確認的活動畫面宣告完整 120 秒能力時，重連先發快照；無回覆才進行有界恢復喚醒，隱藏頁回執取消兜底。

### 修復

- 新連線首次回傳應用清單時保留首個待確認快照，已知安裝變化仍使舊回執失效。
- 桌面預覽匹配靜態兩色邊框探針，恢復舊渲染器預覽呼吸，並移除未使用的觀察字形偏移欄位。
- 為實驗性 Windows 建置補齊固定上游版本的 WebView2 授權及對應原始碼。

### 驗證限制

- 隨附正式 Buddy **0.5.18 / code 40**；舊安裝透過手環頁更新。本地同版本的審查修復包已在本次發布前明確重裝。
- 使用者在兩個真實任務的短時觀察中接受恢復後的效果。韌體記憶體、實際面板幀率、六任務穩定性、長期亮屏與避免重啟仍未驗證。編譯、單測、佈局邊界與 ACK 均不能證明這些結果；見[驗證與相容性](testing.md)。
- GitHub macOS 包繼續使用無證書 ad-hoc 簽章，未經 Apple 公證。Windows 安裝包仍為無簽名實驗性版本，Windows 藍牙／SPP 尚未在 Windows 真機實測。

### 發布自動化

- 新增 Mac arm64/x64 DMG 安裝包、Applications 快捷入口及 SHA-256；保留可攜 ZIP 和現有更新器行為。
- 穩定標籤自動從同一標籤建置 Mac arm64/x64 與 Windows x64/ARM64，四個任務全部成功後才發布。Windows 編譯與打包在 GitHub Actions 上執行，不在本地 Mac 上替代驗證。
- Windows NSIS 安裝包、校驗值及對應原始碼與 Mac 下載一併發布，發布前驗證全部 20 個資產及校驗和。保留唯讀權限的 Windows 手動診斷入口。
- 取代已取消且未發布的 v0.7.4 和 v0.7.5 嘗試，保留其既有標籤。

## [0.7.3] - 2026-11-12

### 修復

- 修復重連時 Buddy 尚未啟動就查詢失敗，導致任務持續執行卻要等新 Hook 才能恢復的問題。以本連線的新安裝清單及成功鏈路探測為依據，60 秒內最多重試兩次準備流程；沒有結果或啟動後失敗不會觸發重複啟動。
- 首次亮屏確認優先於背景裝置查詢；任務意圖或連線歸屬改變時，取消排隊及進行中的恢復。
- 包含已取消發布的 v0.7.1/v0.7.2 所準備的原生 ACK 轉發、真實斷線識別、有界恢復，以及本地證書與 CI 簽名分離。

### 文件與建置

- 三語 README 加入真實 App 首頁 GIF、手環、AI 接入、帳號、設定及資源／顯示頁面截圖。
- 新增實驗性的無證書 Windows x64/ARM64 NSIS 建置、使用者範圍 DPAPI、本地執行時和對應原始碼 Artifact；Windows 安裝與裝置行為尚待驗證。
- 本地 Mac 包使用使用者已有證書，GitHub 繼續無證書模式。短時間實機保持亮屏已確認；長時間和真實中斷後恢復仍列為驗證限制。

## [0.7.1] - 2026-11-12

### 修復

- 原生裝置查詢期間繼續轉送 Buddy 回執；獨立查詢並行且有界，後續喚醒複用已知應用資訊。
- 立即回報藍牙建立失敗／通道關閉，避免把失聯誤判為手環休眠。standby 改為 Buddy 暫未回應，螢幕狀態顯示待確認。
- 任務亮屏開啟時，漏回執後快速重試；目前通道探測成功後可恢復一次有界喚醒，重複失敗不會反覆重開 Buddy。
- 任務結束、設定改變或連線所有者停止時取消排隊及已送出的恢復；遲到的啟動結果不能建立亮屏租約。

### 建置與簽名

- 本地建置要求已有簽名證書，固定 App／Node／傳輸程式識別，保持跨建置的證書程式碼身分穩定。
- GitHub 明確使用無證書 ad-hoc 簽章，不讀取本地鑰匙圈、不接受本地簽名身分，也不建立／匯入臨時證書。
- 補充回歸測試及三語簽名、驗證說明。本地證書授權保留與手動喚醒回執已驗證，實機自動恢復和長期亮屏穩定性仍需測試。

Buddy 維持 **0.5.10**，無需重新安裝手環程式。

## [0.7.0] - 2026-11-11

### 新增

- 自動亮度開關：自動時停用手動滑桿，校驗原生讀回，並在省電結束後恢復原模式。
- 手環亮度與電量狀態 — 在設定 → 手環顯示中使用亮度滑桿，範圍 0–255；省電固定 25，支援充電中顯示及低於 20% 的 Mac 系統通知和 App 提示。
- 預設關閉的任務完成震動：可選短震／長震（預設短震），每個已觀察到的 AI 任務完成時震動一次，支援並行任務及持久化通知去重。
- 設定頁按外觀、執行與同步、手環顯示、任務通知和關於重新分組。
- Buddy 幀率數字輸入，範圍 10–30 FPS；省電時固定 10 FPS 並保留原選擇。
- 英文、簡中、繁中貢獻文件、保持語言的導覽，以及快應用開發指南。

### 改進

- Buddy 角色與資源環使用程式繪製並保留原設計；手環套件圖片僅保留入口圖示，減小本地傳輸體積。
- 多 AI 狀態和任務配色在 Mac 編譯；穩定原生節點、快取幾何／色階及幀預算減少動畫開銷。
- Mac 預覽與 Buddy 共用原生幾何、有效幀率及動畫時間。

### 修復

- 容忍短暫狀態查詢失敗，在充電畫面遮擋後有界恢復活躍 Buddy 一次。
- 替換安裝包前先讓正在回應的 Buddy 正常退出，支援有界等待與取消。
- 資源環接點、雙線及 CPU 弧線更新時累積缺口。
- 亮屏請求失敗、採樣停滯和活動任務重連恢復的處理，限制回呼與重試。
- 頁面／控制器所有權及診斷，可區分隱藏、回執缺失和傳輸故障。

包含無測試後綴的正式 Buddy **0.5.10**。面板實際幀率、電量影響及長時間亮屏可靠性仍未測定，見[驗證指南](testing.md)。
