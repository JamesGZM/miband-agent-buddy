# ADR-016：内置通用 AI 接入

[English](../../en/architecture/ADR-016-bundled-integration.md) · **简体中文** · [繁體中文](../../zh-TW/architecture/ADR-016-bundled-integration.md)

## 问题

平台卡片和依赖 checkout 的安装要求用户理解宿主内部实现，未知工具无法直接使用安装器。接入需要随 App 提供、不干预原任务，并正确处理并行对话。

## 决策

默认请求是跨本地项目和新主对话的用户全局自动上报，采用宿主实际支持的机制，不强制 Hooks。本轮完成可做的持久配置，不得擅自降级为项目范围或仅测通 CLI。最小适配器按需使用，不扩展成安装框架，生命周期独立于项目和其他 App 的私有环境。优先后台观察，在宿主有序边界保留事件顺序；仅有锁和 runtime 水位无法恢复后台到达顺序。必须同步的处理器只做最小有界本地接收或交接；300ms 入口时限不等于总回调时延。宿主启用、真实后续轮次和不同项目自动回报分开验证；原生信任或重载未完成时保持待验证。

对话自动上报分为两个独立选择：已验证的宿主生命周期触发器，以及 内置 CLI 投递。连通或合成回执仅证明通道可用。接入必须建立已加载的主对话回调，并用后续普通用户轮次验证，无需模型临时补发通知。缺少可靠触发或宿主尚未加载时，自动作业仍未完成；模型自行调用与手动上报必须单独标识。不得把名称相似的 CLI/SDK 能力直接套到桌面对话。

桌面程序在 Tauri 启动前处理 `--buddy-cli`，使用内置 Node。宿主 Hooks 或已验证的生命周期回调调用 CLI，经私有 loopback 提交至唯一 runtime，不新增对外 API 或蓝牙拥有者。接入页复制完整接入说明与应用身份，不提供文档链接或安装目录；AI 通过应用注册信息解析入口，选择宿主可靠回调、保留设置并报告缺口。

严格合约只包含匿名 source/session、递增 run/seq 和枚举状态，入口哈希身份，不保留内容。同一对话只有一个主要上报器，回调在后续轮次共用身份。Runtime 负责去重、排序和聚合，已结束轮次不可重开。最多保留 128 个通用对话水位至重设或重启；满额拒绝新身份而不挤掉活动。每对话限流另预留一次结束事件。连接不是对话。

CLI 本机接收时限 300ms，不等待设备。宿主限制进程启动时间，按对话串行化回调，避免无界进程堆积；独立对话可并发调用 CLI。调度和进程启动另有延迟。失败返回明确结果但继续原任务，不轮询或反复重试。设备交付沿用串行传输与快照合并。等待提醒必须有可靠解除；静默或断线不代表完成。

## 替代方案

额外对外 API 重复入口；MCP 增加配置和工具发现，却不提供命令型 Hooks 的生命周期触发，因此移除服务、入口和专用 schema／测试。下载源码或要求系统环境不符合自包含安装。等待手环会阻塞任务，盲目后台提交无法证明接收。宿主配置仍有差异，但无需平台选择页。

## 退役源码安装器

从 scripts 目录移除 `install_agent_hooks.mjs`、`install_codex_hooks.mjs` 及安装器专属测试。继续保留旧平台自动写入器会与宿主自选的通用接入冲突。公开命令 `npm run hooks:install` 保留为只读 `buddy-cli.mjs guide` 别名，不再写入配置，也不支持旧安装参数。测试验证该入口输出完整指南且不修改宿主配置，并保留两个 Mac 兼容入口。既有事件发送器、接收合约与用户本机备份不变。ADR-004/013 的安装器历史记录不代表当前操作方式。

## 兼容性

桌面包改用共用的明确资源边界，不再复制整份开发目录和清单。保留生产 JavaScript 模块、最小模块类型/版本/授权信息，以及 CLI guide/help 使用的唯一当前接入指南；不带入 fixtures、测试、额外笔记或开发命令。完整授权/来源资料在独立区域保留。整份清单会泄露已退役安装命令，删除当前指南则会破坏离线 CLI。以封装测试与搬移包执行验证边界，不改变运行时行为。

聚合状态以 `source: "buddy-activity"` 标识子系统，新增 `scope: "aggregate"`。原先写死的 `codex-hooks` 不是实际来源归因。计数与时间戳覆盖所有对话，不能据此判断某个轮次状态或 Hooks 配置，应验证该轮次的上报回执。匿名输入 source 身份不变，也不在状态中暴露。

保留旧 Hook 端口、兼容入口、v1 合约、私密路径和 npm 命令。CLI 标志及匿名字段不变。明确退役 MCP 入口，接入 AI 应预览后仅移除宿主的 Buddy MCP 注册项；不自动迁移旧 Hooks 或重复上报。不改手环、不新增云端或遥测、不发布或安装全局配置。

## 入口文件身份

内置 CLI 和 runtime 比较规范化后的真实文件身份，不再直接比较模块 URL 与 argv 路径。Node 可能解析符号链接入口，同时在 argv 中保留别名，字符串比较会静默跳过启动。文件系统查询由一个 runtime adapter 负责，不进入 core；缺失或非文件参数按导入处理。仅比较文件名可能误启动被导入的服务，要求所有调用方自行规范化路径也不可靠。默认解析和 preserve-symlinks-main 都保持直接入口行为，不改变协议或配置。真实子进程的链接目录回归测试先重现空说明输出，身份判断和生产资源导入测试保留导入无副作用；发布归档测试另在链接的 macOS 临时目录验证。

## 证据

测试覆盖内容拒绝、身份隔离、同毫秒与旧轮次排序、去重、结束、容量／限流、隔离接收器、超时和真实 CLI 并发进程。新轮次首个 working 事件请求有界开始唤醒；同轮次 thinking 视为恢复，工具流量不反复打开手环。回归测试覆盖首次 working、同轮切换和下一轮；既有冷却与连接恢复保留。签名包、迁移和已安装 App 分别验证。宿主回调与物理亮屏仍需观察。
