# ADR-015：合并事件唤起

[English](../../en/architecture/ADR-015-coalesced-event-wake.md) · **简体中文** · [繁體中文](../../zh-TW/architecture/ADR-015-coalesced-event-wake.md)

## 问题

重复的任务开始 Hook 会在 Buddy 已显示且保持亮屏时再次请求原生启动。冷却时间只是延后重复打开，没有消除副作用。

## 决策

Mac 继续计算聚合状态、优先级与任务颜色。当前连接的新鲜 ACK 确认页面可见、亮屏已接受且租约未过期时，事件优先发送快照。并发 Hook 合入已有的有界显示事务，快照携带最新聚合结果。每任务完成记录独立于显示合并。若下一个回执明确报告隐藏或关闭亮屏，同一事务可在原截止时间内启动一次。用户手动操作保留现有原生唤起行为。

## 替代方案

永久按会话与事件去重会吞掉同一对话的合法后续轮次；延长冷却只会推迟重复打开。手环推断任务会违反职责并增加设备负担。

## 兼容与证据

不改变设备协议或渲染器。旧版 Buddy 缺少前台证据时保留原生唤起。暂停、断开、安装、恢复及定时器边界保持。假时钟测试覆盖双会话、突发事件、合法后续轮次、注意与完成、延迟启动、隐藏竞争和缺失 ACK。本机健康计数区分原生启动和快照唤起。这些证据证明消除了重复打开，不能证明物理设备重启的原因或已解决。
