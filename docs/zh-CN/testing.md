## 自动检查

完成[开发环境设置](development/README.md)后，在仓库根目录运行：

```sh
npm run build
npm test
npm run check:architecture
cargo test --locked --manifest-path apps/desktop/src-tauri/Cargo.toml
cargo test --locked --manifest-path native/transport/Cargo.toml
cargo test --locked --manifest-path native/transport/Cargo.toml -p corelib device::xiaomi::sar::tests
npm run build:desktop
```

运行时与手环测试使用注入的时钟、传输及平台适配器。契约测试覆盖启动、设置恢复、异步图像、首次引导与协议兼容；架构检查执行[架构指南](architecture/README.md)的所有权边界。

PR 仅检查源码，不生成发布包。发布构建额外验证两种 Mac 架构、包内容、签名完整性及归档移动后运行。结果见 [GitHub Actions](https://github.com/JamesGZM/miband-agent-buddy/actions)。

| 小米手环 9 标准版 | 应用的目标设备，尚需实机确认 |

已在 NFC 版固件 3.1.32 验证 Buddy 0.5.18 安装与软件通信，包括明确重装同版本的审查修复包。用户在较早的两个真实任务短时检查中接受恢复后的呼吸／Loading 效果；115 秒诊断观察未记录到新增页面重建、传输关闭、ACK 超时或页面错误。这些观察不能证明实际面板帧率、耗电、六任务稳定性、持续亮屏或避免重启。最新重装回执不是新的实机视觉或耐久结果。

本地亮屏修复增加了采样抛错／卡住时继续续期、过期资源显示未知、无重叠采样、停止后忽略迟到结果，以及亮度负值回执和超时重试测试。它们是软件证据，不代表长时间实机验收完成。

## 手工验收

尽可能使用测试账号与设备。不要为了测试引导而清除已有账号或配对。

1. 没有保存账号时启动，检查欢迎入口、服务地区、设备选择与配对说明。
2. 有保存设备时重启，确认主题与设置恢复，预览不闪烁，也不重复首次引导。
3. 图像未缓存时切换主题，确认完整画面替换，没有空白或混合图层。
4. 检查手环页面中未安装、已安装、已更新状态，分别判断传输完成与安装确认。
5. 在活动同步开启和关闭时测试手动唤醒与设置，同时观察真实屏幕和 App 回报。
6. 运行重叠 AI 任务；一个结束不影响另一个，最后一个结束后才开始待机倒数。
7. 检查省电、断线恢复、关闭窗口和退出，测试后恢复原设置。
8. 开启任务亮屏后，持续观察超过以往熄屏时间，记录熄屏时任务、连接、最后同步时间与亮屏诊断。分别验证长时间思考、工具执行、等待确认、最终结束及停止同步后的本地释放。

## 当前限制

- 不同固件的蓝牙恢复与长期任务亮屏仍需验证。已测试固件可能意外结束长时间亮屏；API 成功不代表物理屏幕亮着。
- 手环安装可能完成，但最终结果未传回 Mac。先重连、检查运行版本，再决定是否重装。
- 动画更新频率是调度目标，尚未测量面板实际帧率与功耗。
- GitHub macOS 包使用无证书 ad-hoc 签名，未经 Apple 公证，首次打开可能需要标准批准流程。
- AI 接入依赖工具提供的生命周期事件，主题名称不代表该产品存在原生 Hooks API。

可复现问题通过[支持指南](SUPPORT.md)报告。公开报告不要包含账号、设备密钥、提示词或对话。

在小米手环 9 NFC 固件 3.1.32 上，用户确认从手动亮度 202 降至省电 25 时能明显看到变暗。原生读回与 App 已验证自动开关、禁用手动控制、模式恢复及手动值保留。安装前先让有响应的旧页面退出，后续本地更新已自动恢复同步。这是短时实机检查，不代表续航测量或证明固件唯一根因。用户还确认，拔下后重新连接充电器时，充电状态更新加快，Buddy 无需手动打开即可自行恢复。运行时容忍一次临时状态探测失败，结合设备事件与约 5–6 秒轮询兜底。这次短时恢复检查不代表蓝牙始终没有中断。低电量系统通知显示仍需系统验证；阈值和去重测试不能证明 macOS 已显示通知。

2026-11-12，本地 App、随包 Node 和传输程序已使用已有 Apple Development 证书及各自固定标识签名。两个内容不同的测试二进制产生相同的证书 designated requirement。新身份授权一次后，用户确认重启同一份 App 没有再次弹窗并恢复连接，随后实际手动唤醒操作取得匹配亮屏回执。重启后的这次短时检查未出现 ACK 超时或传输关闭。CI 模式选择已由本地测试验证，没有发布新 GitHub 版本；不代表已验证未来漏回执时的实机自动恢复，或所有 macOS 版本的跨构建权限保留。

本地启动准备恢复修复：328 项 Node 测试通过，覆盖无需新 Hook 的重连恢复、有次数限制的准备重试及首次查询优先级。用户已确认观察 2–3 分钟时持续亮屏，并进行五分钟本地健康记录观察。这仍不代表真实无线中断后的自动恢复或长时间耐久已获实机验证。

**Windows 蓝牙／SPP 尚未在 Windows 真机实测。** Actions 编译、Rust 测试和 NSIS 打包成功不代表配对、手环通信、重连或持续运行已验证。

随后已在同一 NFC 设备安装并收到 Buddy 0.5.19 / code 41 的回执。突发绘制合并已通过回归测试；这证明安装与通信，不是新的双 Agent 长时间实机验收。产品的目标摆放位置为主机电脑旁的桌面。
